MX Keys Bridge — Pairing

This extension only accepts commands from the MX Keys plugin after it proves it knows this machine's pairing code — that's what stops another local process from silently muting your mic, stopping your screen share, or leaving a call. Click "Fetch from plugin" while Logi Options+ is running, or paste the code by hand from bridge-secret.txt (macOS: ~/Library/Application Support/MxKeysGoogleMeet/, Windows: %LOCALAPPDATA%\MxKeysGoogleMeet\).
